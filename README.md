# spring-shopping

## 요구사항
1. 상품 추가
   - 상품의 이름, 가격, 이미지 URL를 입력할 수 있어야한다.
   - 유효성
     - 이름
       - 상품 이름은 공백을 포함하여 최대 15자까지 입력할 수 있다.
       - 상품 이름은 아래 특수 문자만 가능하다.
         - ( ), [ ], +, -, &, /, _
       -  상품 이름에는 비속어를 포함할 수 없다.
     - 가격
       - 상품 가격은 0이상이여야합니다.
     - 이미지 URL
       - 빈 값일 수 없습니다.
2. 상품 조회
3. 상품 수정
   - 상품의 이름, 가격, 이미지 URL를 수정할 수 있어야한다.
       - 유효성
           - 이름
               - 상품 이름은 공백을 포함하여 최대 15자까지 입력할 수 있다.
               - 상품 이름은 아래 특수 문자만 가능하다.
                   - ( ), [ ], +, -, &, /, _
               -  상품 이름에는 비속어를 포함할 수 없다.
           - 가격
               - 상품 가격은 0이상이여야합니다.
           - 이미지 URL
               - 빈 값일 수 없습니다.
4. 상품 삭제
  - 식별자를 받아 상품을 삭제할 수 있어야한다.
  - 유효성
    - 식별자에 해당하는 상품이 존재해야한다.
