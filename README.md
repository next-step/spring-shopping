# spring-shopping

## 요구사항
1. 상품 추가
   - 상품의 이름, 가격, 이미지 URL를 입력할 수 있어야한다.
   - 유효성
     - 이름
       - 상품 이름은 공백을 포함하여 최대 15자까지 입력할 수 있다.
       - 상품 이름은 아래 특수 문자만 가능하다.
         - ( ), [ ], +, -, &, /, _
       -  상품 이름에는 비속어를 포함할 수 없다.
     - 가격
       - 상품 가격은 0이상이여야합니다.
     - 이미지 URL
       - 빈 값일 수 없습니다.
2. 상품 조회
3. 상품 수정
   - 상품의 이름, 가격, 이미지 URL를 수정할 수 있어야한다.
       - 유효성
           - 이름
               - 상품 이름은 공백을 포함하여 최대 15자까지 입력할 수 있다.
               - 상품 이름은 아래 특수 문자만 가능하다.
                   - ( ), [ ], +, -, &, /, _
               -  상품 이름에는 비속어를 포함할 수 없다.
           - 가격
               - 상품 가격은 0이상이여야합니다.
           - 이미지 URL
               - 빈 값일 수 없습니다.
4. 상품 삭제
  - 식별자를 받아 상품을 삭제할 수 있어야한다.
  - 유효성
    - 식별자에 해당하는 상품이 존재해야한다. 


## 배운 것 
1. 스코프함수에서 this, it 을 생략하고 쓴 변수와 상위 스코프의 변수명이 겹치면, 컴파일 에러는 발생하지 않고, 상위 스코프를 참조한다.

## 룰로 가져가볼 것?
1. dto 클래스에서 entity를 참조하게 할지?(toEntity) 혹은 스코프 함수로 반환할지?
2. 요청/응답 dto 널처리 어떻게 할지?
   - request -> dto (널체크) -> entity(? 구분이 명확) -> queryDto -> response(json 때문에 nullable 해야하긴함)
